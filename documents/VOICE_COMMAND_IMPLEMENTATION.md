# 音声コマンド実装計画

## 概要

KumiTalkアプリケーションに音声コマンド機能を実装し、ユーザーが声でアプリケーションを操作できるようにする。

## 実装対象のコマンド

### 1. ステップ移動コマンド
- `ステップ {数字}` - 指定したステップに移動
- `次` / `次のステップ` - 次のステップに移動
- `戻って` / `前のステップ` - 前のステップに移動
- `最初` / `最初に戻る` - 最初のステップに移動
- `最後` / `最後まで進む` - 最後のステップに移動
- `全て` / `全てのステップ` / `すべて` / `すべてのステップ` - 全ステップ表示

### 2. 画像操作コマンド
- `拡大` / `画像拡大` - 現在のステップ画像を拡大表示
- `縮小` / `画像縮小` - 拡大表示を閉じる

### 3. 音声制御コマンド
- `しゃべらないで` / `止まって` / `ストップ` - 音声出力を停止
